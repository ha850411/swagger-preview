# swagger-preview
 swagger 可預覽的 api 文件類型: json, yaml

## Step1 
clone 該項目

## Step2
開啟 chrome extension 載入未封裝項目並選擇該項目

## Step3
在 github 中對欲預覽的 api 文件點擊 [ Raw ] 按鈕開啟 raw 頁面

## Step4
勾選自動偵測或是手動點擊按鈕導向 swagger editor
